# SAYING.

> 아는 문장에서, 나의 말로.

SAYING.은 영어의 핵심 문장 패턴을 이해하고, 단어를 바꾸고, 직접 문장을 만들어 실제 대화로 연결하는 성인 영어 회화 학습 웹앱입니다. 프레임워크와 빌드 과정 없이 실행할 수 있는 모바일 우선 MVP이며, 현재는 검증된 샘플 콘텐츠로 전체 학습 흐름을 체험하도록 구성되어 있습니다.

## 서비스와 학습 철학

- 암기에서 끝내지 않고 `패턴 이해 → 단어 변형 → 직접 쓰기 → 상황 회화 → 누적 복습`으로 이어집니다.
- 10·20·30분 중 오늘 가능한 만큼을 골라 부담 없이 시작합니다.
- 초급·중급·고급 진도를 독립적으로 관리하는 구조를 지향합니다.
- 두 사용자가 각자 공부하고, 허용한 기록만 공유하는 학습방을 지향합니다.
- 자동 생성보다 사람이 검수한 자연스럽고 정확한 영어 콘텐츠를 우선합니다.

## 현재 구현된 기능

- 홈 대시보드, 10·20·30분 코스 선택 및 브라우저 저장
- 5단계 데모 학습: 패턴, 단어 변형, 직접 쓰기, 상황 회화, 완료
- Web Speech API를 이용한 기본 문장 발음 재생
- 검수된 정답을 이용한 데모 문장 채점
- 초급 35개·중급 35개·고급 30개, 총 100개 회화 패턴과 실제 대화 예문·번역·발음 듣기
- 난이도별 패턴 필터, 펼쳐보기, 스마트 복습, 2인 학습방, 마이페이지 UI
- 학습 중 현재 단계 저장 및 재진입
- 모바일·태블릿·데스크톱 반응형 화면과 키보드 포커스 구조
- Supabase용 초기 스키마와 RLS 정책 초안

현재 화면의 사용자·통계 데이터는 데모 데이터입니다. 100개 패턴의 회화 예문은 확인할 수 있지만, 모든 패턴에 대한 5단계 학습 콘텐츠는 아직 첫 번째 대표 패턴에만 연결되어 있습니다. 실제 Supabase 인증, CRUD, 초대 코드 발급, 관리자 편집 화면도 아직 연결되지 않았습니다.

## 기술 구조

- HTML5
- CSS3 및 CSS Custom Properties
- Vanilla JavaScript ES Modules
- 브라우저 `localStorage` (MVP 진행 상태)
- Supabase Auth/PostgreSQL/RLS 연결을 위한 `schema.sql`

```text
.
├── index.html          # 전체 화면과 접근 가능한 문서 구조
├── style.css           # 디자인 시스템 및 반응형 UI
├── script.js           # 라우팅, 학습 단계, 채점, 로컬 상태
├── schema.sql          # Supabase 테이블·타입·RLS 초안
├── assets/
│   ├── logo.svg        # 워드마크
│   └── app-icon.svg    # 앱 아이콘
└── README.md
```

## 설치 및 실행

빌드나 패키지 설치가 필요하지 않습니다. ES Module을 안정적으로 불러오기 위해 파일을 직접 더블 클릭하기보다 로컬 서버로 실행하세요.

```bash
python3 -m http.server 8080
```

그 후 `http://localhost:8080`을 엽니다. Node.js가 있다면 `npx serve .`도 사용할 수 있습니다.

## Supabase 연결 준비

1. 별도의 Supabase 프로젝트를 생성합니다.
2. SQL Editor에서 `schema.sql`을 실행합니다.
3. 프로젝트 URL과 `anon` 공개 키를 별도 `config.js`에 둡니다. 이 파일은 공개 키만 포함하며 저장소 정책에 맞게 관리합니다.
4. `service_role` 키는 절대로 브라우저 코드나 저장소에 넣지 않습니다.
5. Supabase JS 클라이언트를 추가하고 현재 `localStorage` 상태를 인증 사용자 기반 쿼리로 교체합니다.
6. 관리자 권한은 클라이언트 요청으로 변경하지 말고 SQL Editor 또는 신뢰된 서버에서만 설정합니다.

`schema.sql`은 자신의 학습 세션·답안만 수정하도록 제한하고, 공개를 허용한 문장만 같은 학습방 구성원이 읽도록 하는 RLS의 출발점입니다. 운영 배포 전에는 Supabase의 최신 권장 사항에 맞춘 정책 테스트가 필요합니다.

## 콘텐츠 관리 기준

콘텐츠는 `draft → review → approved → published` 단계를 거칩니다. 일반 학습 화면은 `published` 상태만 읽어야 합니다. 각 패턴은 기본 문장, 한국어 의미, 문법 설명, 활용 상황, 변형 예문, 직접 쓰기 문제, 허용 정답, 회화 문맥과 출처를 함께 관리합니다.

문법, 어순, 시제, 동사 형태, 전치사, 관용 표현, 번역, 실제 회화 자연스러움을 사람이 검수합니다. Cambridge Dictionary, British Council 등 신뢰할 수 있는 참고 자료와 검수일을 기록하고, 자동 검사만으로 승인하지 않습니다.

## 브랜드 가이드

### 로고

- 워드마크는 항상 `SAYING.`으로 표기합니다.
- 영문 글자는 `#1E2329`, 마침표는 코랄 `#FF695B`입니다.
- 로고 비율을 변형하거나 그림자·그라디언트를 적용하지 않습니다.
- 앱 아이콘과 워드마크 원본은 `assets/*.svg`를 사용합니다.

### 색상

모든 색은 `style.css`의 `:root` CSS 변수에서 중앙 관리합니다.

| 용도 | 값 |
|---|---|
| Primary | `#FF695B` |
| Text | `#1E2329` |
| Background | `#F7F6F2` |
| Subtle Accent | `#FFE5DF` |
| Card | `#FFFFFF` |
| Border | `#E6E4DE` |

배경, 버튼, 카드, 진행률을 포함한 모든 요소에 그라디언트를 사용하지 않습니다. Primary 위의 어두운 텍스트 또는 Text 위의 흰색처럼 읽기 쉬운 조합을 사용합니다.

### 타이포그래피

- 영문: Inter
- 한글: Pretendard 우선, Noto Sans KR 폴백
- 본문은 장식보다 가독성을 우선하며, 영어 패턴에는 Inter를 명시합니다.

## 테스트

브라우저에서 다음을 확인합니다.

1. 10·20·30분 선택이 새로고침 후 유지되는지
2. 학습 시작부터 5단계 완료까지 이동하는지
3. `I want to learn English.`가 정답 처리되는지
4. 학습 중 나갔다가 다시 들어오면 단계가 유지되는지
5. 360px 모바일 폭과 데스크톱에서 내용이 잘리지 않는지
6. Tab 키만으로 주요 버튼과 입력 요소에 접근 가능한지
